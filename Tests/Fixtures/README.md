# Audio fixtures

Generated tones and silence; no third-party music. `sample.flac` is copied from `docs/sample.flac` (generated by `docs/make-sample.sh`). Other files are a two-second 440 Hz tone at 8 kHz, converted with ffmpeg to the named encoding. Tagged formats contain First Song / Test Artist / Test Album, album artist Test Artist, track 2/3, and disc 1/2. Raw AAC and AIFF need not expose those tags through AVFoundation. Fixtures are bundled only with test targets. Running tests needs no ffmpeg.
